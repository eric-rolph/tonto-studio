# Hardware references and matching

Research and first measurements: 25 September 2026. The live [Reference lab](https://tonto-studio.ericrolph.workers.dev/reference.html) contains 25 source entries and 13 playable studies. These distinguish original hardware, related models, clones, patch documents and finished music. Only one hardware clip has been fitted so far; the five cabinets have **not** been validated as nearly identical replicas.

## Artist and song evidence

- **Wendy Carlos / Switched-On Bach:** [the artist’s notes](https://www.wendycarlos.com/%2Bsob.html) identify the Moog realizations. Do not silently equate her system or multitrack recording chain with a stock System 55 patch.
- **Anthony Marinelli / Thriller and other ARP examples:** [his own patch library](https://anthonymarinellimusic.com/pages/free) is a stronger lead than recreations based only on listening. The app’s two-oscillator bass is explicitly a starting point, not a certified transcription.
- **Ben Burtt / R2-D2:** [Lucasfilm’s production account](https://www.starwars.com/news/5-iconic-star-wars-sound-effects-and-how-they-were-made-starwars-com) supports vocal/electronic performance as the target. A synth preset alone cannot reproduce the voice, gestures, editing and playback speed.
- **Suzanne Ciani / Buchla Concerts 1975:** [the artist’s release](https://suzanneciani.bandcamp.com/album/buchla-concerts-1975) supplies a musical reference, not an isolated, fully documented test patch.
- **Morton Subotnick / Silver Apples of the Moon:** [Library of Congress](https://www.loc.gov/static/programs/national-recording-preservation-board/documents/SilverApples.pdf) identifies **Buchla 100**, so this is not evidence for a Buchla 200 calibration.
- **Pink Floyd / On the Run:** the [band archive](https://archive.pinkfloyd.com/news/) documents the EMS context. Distinguish Synthi AKS/sequencer from VCS3; the app sequence is a technique study with its own notes.
- **Stevie Wonder / TONTO:** [National Music Centre](https://www.studiobell.ca/assets/documents/TONTO-Week-puts-holy-grail-of-synthesizers-in-the-spotlight-from-November-14-18.pdf) documents the instrument’s artist history. An inventory of the cabinets does not establish which ones were cross-patched on a particular song.

## First measured study

Reference: `Cosmic Clay 2_bip.wav`, left channel, 2.229115646 seconds, 44,100 Hz / 16-bit PCM. SHA-256, exact patch, baseline, capture options and fitting history are in [the machine-readable report](../public/reference-easel-report.json). No third-party audio is committed or served.

The initial guess uses A4, a 0.1-second gate, FM ratio 0.47 and the Buchla low-pass gate. A five-pass coordinate search adjusts seven timbre/envelope controls at the **original sample rate**. It does not infer the hardware controls. An initial A3 guess based on periodicity alone was rejected after spectral inspection showed the strongest component near 440 Hz; the published baseline begins after that manual correction.

| Measurement | Before fitting | After fitting |
| --- | ---: | ---: |
| RMS-matched average spectrum error | 0.2434 | 0.2061 |
| Aligned waveform NRMSE, fitted gain/polarity | 0.5792 | 0.5297 |
| Aligned envelope error | 0.3399 | 0.3371 |
| Absolute waveform correlation | 0.8152 | 0.8482 |
| Onset-aligned fit objective | 0.4590 | 0.3793 |

The average spectrum error fell about 15%; waveform error fell about 9%. The waveform residual remains substantial, and envelope improvement under the waveform alignment is small. **This is an improved single-clip approximation, not a nearly identical sound claim.** The original chain and controls are unknown, and no held-out notes were used. The period estimator picks a subharmonic in this sound, so its cents readout should not be treated as a precision tuner.

Reproduce the final measurements without repeating optimization:

```powershell
node scripts/measure-reference.mjs 'C:\path\Cosmic Clay 2_bip.wav' 'C:\path\outside-repo\measurements'
```

Append `--refit` to repeat the 71-evaluation search. The script checks the source hash. The browser uses three passes for interactive fitting, so it may find a different result from a fresh seed; the measured preset preserves the five-pass result.

## Changes shipped

- Reference lab: local import, original PCM WAV rate/depth inspection, channel/crop selection, deterministic offline rendering, direct audio-jack taps, RMS-matched audition, waveform/spectrum/envelope plots, selected-control fitting, cancellation, patch/report export and 32-bit float candidate WAV export.
- Thirteen reference patches, including the measured study and ARP → Buchla LPG, Buchla → Moog ladder, cross-cabinet ring modulation and a three-envelope ARP kick technique. Patch memory receives lab saves without interrupting an open studio recording.
- Moog filter audio now **replaces** its internal normal mixer when patched. It previously leaked 35% internal oscillator blend into external signals. Added explicit oscillator A/B/sub mixer controls for isolated tests; unpatched default levels are preserved.

The original studio tape exporter is still 16-bit. The lab’s 32-bit float export preserves the rendered DSP output without another integer quantization step; it cannot add information to a 16-bit reference recording.

## How to extend fidelity

For each exact hardware revision, obtain dry calibrated recordings with patch photos and CV/gate logs. Capture isolated oscillator waveforms at multiple pitches, filter cutoff/resonance/drive sweeps, envelope rise/fall, LPG tails, FM/ring sidebands, and repeatable cross-cabinet excitation. Reserve different notes and levels for validation. Then change the relevant DSP model and compare both training and held-out captures.

For digital modules, use the manufacturer’s [Plaits](https://pichenettes.github.io/mutable-instruments-documentation/modules/plaits/), [Rings](https://pichenettes.github.io/mutable-instruments-documentation/modules/rings/) and [Clouds](https://pichenettes.github.io/mutable-instruments-documentation/modules/clouds/) documentation and licensed source as the technical baseline. The current original DSP approximations cannot cover those firmwares’ complete behavior through preset fitting alone.
